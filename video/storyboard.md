# DEEP BNB — 60-Second Demo Video Storyboard

**Project:** DEEP BNB — "Deep liquidity for the agent economy."
**Purpose:** Agent ID Hackathon submission (demo video, 60 seconds)
**Format:** 60-second screen-recorded product demo + voiceover, 16:9, English narration
**Visual style:** Dark navy to match the website; navy dolphin logo; clean sans-serif on-screen text
**Voiceover pace:** ~133 words / 60 seconds (~133 wpm — natural demo pace)

> **Production status — storyboard + script ONLY.**
> This document is the storyboard and narration script. No video has been produced.
> All screenshots and screen recordings listed in the Shot List are to be captured
> AFTER the website build is complete. Video production (recording, editing,
> voiceover) is a separate next stage.

## Project facts used (no invented figures)

- Token: DEEP, BNB Chain, fixed supply 1,000,000,000, 18 decimals.
- Economic coordination layer for AI agents that own an Agent ID (.ai identity).
- Four pillars: (1) deep liquidity pools for verified .ai agents only,
  (2) reputation staking, (3) launchpad access for verified agents,
  (4) DEEP as settlement for agent-to-agent payments.
- Flagship feature: airdrop claim of 1,000 DEEP per Agent ID, verified on-chain
  via the SPACE ID registry — one claim per Agent ID, 300,000,000 DEEP pool.
- Founder: Rafeal — X: https://x.com/coremsn9099
- No contract address, TVL / user count, or token price appears anywhere in this
  video. Do not add any. (If a contract address is ever shown on screen, insert
  only the verified deployed address — never a placeholder or invented value.)
